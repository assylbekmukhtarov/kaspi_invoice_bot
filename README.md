# Kaspi Invoice Merger Bot (Telegram, Python / aiogram 3)

Бот объединяет накладные Kaspi для печати:
- Термопринтер: 75×120 мм и 100×150 мм
- A4: во весь лист, 4/8/9 накладных на A4
- Простое объединение любых PDF

Дополнительно:
- Обработка экспресс-накладных и накладных из нескольких частей (эвристика по имени файла/ID)
- Принимает ZIP и PDF (по одному или пачкой)
- Опциональная загрузка накладных из кабинета продавца Kaspi (через Playwright; требуется логин)
- Быстро и стабильно (PyMuPDF)

## Быстрый старт
1) Python 3.10+
2) Скопируйте `.env.example` в `.env` и вставьте токен бота
3) Установка зависимостей:
```bash
pip install -r requirements.txt
```
4) (Опционально) Установите браузеры Playwright:
```bash
playwright install
```
5) Запустите:
```bash
python -m app
```

## Мониторинг доступности сайта
Отдельный процесс, не зависящий от бота, проверяет `MONITOR_URL` и шлёт алерт в Telegram (тем же ботом) на `MONITOR_CHAT_ID`, если сайт упал.

Настройки в `.env`:
```
MONITOR_URL=https://agroscope.pro
MONITOR_INTERVAL_SECONDS=300        # проверка раз в 5 минут, когда всё ок
MONITOR_DOWN_INTERVAL_SECONDS=1200  # проверка раз в 20 минут, пока сайт недоступен
MONITOR_SSL_WARN_DAYS=14            # предупредить, если до конца SSL-сертификата меньше 14 дней
```

Запуск:
```bash
python -m app.monitor
```

Сообщение шлётся один раз при переходе в состояние "недоступен" и один раз при восстановлении — не на каждой проверке.

Раз в сутки (для `https://` адресов) проверяется срок SSL-сертификата: если осталось меньше `MONITOR_SSL_WARN_DAYS` дней, приходит предупреждение — по одному в день, пока сертификат не обновят.
