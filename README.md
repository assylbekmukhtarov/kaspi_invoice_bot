# Kaspi Invoice Merger Bot (Telegram, Python / aiogram 3)

Бот объединяет накладные Kaspi для печати:
- Термопринтер: 75×120 мм и 100×150 мм
- A4: во весь лист, 4/8/9 накладных на A4
- Простое объединение любых PDF

Дополнительно:
- Обработка экспресс-накладных и накладных из нескольких частей (эвристика по имени файла/ID)
- Принимает ZIP и PDF (по одному или пачкой)
- Опциональная загрузка накладных из кабинета продавца Kaspi (через Playwright; требуется логин)
- Быстро и стабильно (PyMuPDF)

## Быстрый старт
1) Python 3.10+
2) Скопируйте `.env.example` в `.env` и вставьте токен бота
3) Установка зависимостей:
```bash
pip install -r requirements.txt
```
4) (Опционально) Установите браузеры Playwright:
```bash
playwright install
```
5) Запустите:
```bash
python -m app
```
